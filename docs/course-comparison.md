## 3. 記事にそのまま使える切り口

1. **「創業スクールの受講料は79倍も違う」** — 5,000円（板橋区）vs 396,000円（川崎KSP）。同じ「特定創業支援等事業」で同じ証明書が出る
2. **「無料で登録免許税を7万5千円安くする方法」** — 名古屋市・高松市・川崎市・福岡市の無料枠を並べる
3. **「オンラインだけで証明書が取れる自治体」** — 川崎みらい海図（無料）、板橋区（5,000円・代替課題で完結可）、横浜のオンデマンド3件
4. **「女性起業家向け講座がある自治体」** — 横浜（ブルーコンパス）、川崎（すくらむ21・6,000円）、福岡（スプラウト、LEADIA）、川口（AFEKT）
5. **「市のサイトを見ても受講料は分からない」** — 10自治体中4つが金額非公開。高松市は商工会議所側で初めて判明。**この不透明さ自体がサイトの存在価値**

## 5. 副次的な重要発見（収集方法に関わる）

**高松商工会議所は WordPress + The Events Calendar を使っており、以下がすべて動作しました。**

- `schema.org/Event` の JSON-LD（ISO8601の開始/終了日時、住所、`eventAttendanceMode`、`offers`）
- REST API: `/wp-json/tribe/events/v1/events`（`modified_utc` を含む）
- iCal: `/eventcalendar/?ical=1`
- robots.txt は `/cms/` のみ Disallow で、これらは許可

**ただし共通仕様ではありません。** 他4会議所を検証したところ The Events Calendar は3件が404（mcci.jpは接続失敗）。一方で**標準の WordPress REST API と RSS は3件すべてで200**でした。那覇商工会議所は `seminar` というカスタム投稿タイプを API で公開しています。

→ 商工会議所チャネルは「WordPressが主流で、APIが生きている」。収集手順は
`/robots.txt` 確認 → `/wp-json/wp/v2/types` で投稿タイプを発見 → 該当エンドポイントを収穫、が定型化できます。

**注意点:** The Events Calendar の `offers.priceCurrency` は "USD"、`availability` は "inStock"、`validFrom` は 1970-01-01 と、**プラグインの初期値がそのまま出力されています**。price="0"（無料）は正しいものの、通貨・在庫・開始日は信用してはいけません。
