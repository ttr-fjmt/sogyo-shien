# SEOキーワード設計・サイト構造仕様

**作成日:** 2026-09-09
**前提:** 収益導線は会社設立・創業融資への送客。主戦場は「成果 × 地域」のロングテール。

> **調査ツールの限界:** 競合の把握には米国インデックスの検索を使用。**日本のGoogle実SERPの順位測定ではない**。検索ボリュームとキーワード難易度は専用ツールで別途実測すること。

---

## 1. キーワードの3層と、狙う場所

| 層 | 例 | 現状の占有者 | 判断 |
|---|---|---|---|
| 制度名 | 「◯◯市 特定創業支援等事業」 | 市の公式（.lg.jp） | **狙わない**。勝てず、母数も小さい |
| 汎用・成果 | 「会社設立 登録免許税 半額」 | 弥生、V-Spirits、中小企業庁、司法書士多数 | **記事1本のみ**。飽和 |
| **成果 × 地域** | 「◯◯市 会社設立 費用」 | freee（大都市のみ量産）、アントレサロン（一部） | **★主戦場** |
| **横断比較** | 「創業塾 費用 比較」「無料 創業セミナー オンライン」 | **不在** | **★独自価値** |

**空白の実証:** 「松本市 会社設立 創業支援 補助金」で検索したところ、freeeもアントレサロンも該当ページを持たず、SERPは汎用記事・市の公式・**松戸市**（「松」の誤マッチ）で埋まりました。中規模以下は空いています。

## 2. サイト構造

```
/                                    トップ（診断導線）
/shindan/                            診断ツール（地域×創業前後×法人個人）
│
├─ /area/{pref}/{city}/              ★地域ページ ×1,459
│    例: /area/kanagawa/yokohama/
│
├─ /seido/                           制度別（成果軸）
│    /seido/registration-tax/        登録免許税を半額にする
│    /seido/jizokuka-sogyo/          持続化補助金〈創業型〉上限250万
│    /seido/sogyo-hosho/             創業関連保証の特例
│    /seido/jfc-kinri/               日本公庫の金利引き下げ
│
├─ /compare/                         ★横断比較（独自価値）
│    /compare/fee/                   創業スクール受講料ランキング
│    /compare/free/                  無料で証明書が取れる自治体
│    /compare/online/                オンライン完結で取れる講座
│    /compare/women/                 女性起業家向け
```

**イベントに個別URLを与えないこと。** 地域ページ内のモジュールとして描画する。寿命が2〜3か月しかなく、URL資産が腐るため。

## 3. 地域ページのタイトル・見出し仕様

### title（30〜40字目安）

```
{市区町村名}で会社設立｜登録免許税が半額になる制度と創業セミナー【{YYYY}年{M}月更新】
```

例: `横浜市で会社設立｜登録免許税が半額になる制度と創業セミナー【2026年9月更新】`

**バリエーション（重複回避）** — 1,459件で同一パターンだとテンプレ判定を受けやすいので、市の特性で3系統に振り分ける。

| 条件 | title |
|---|---|
| 独自の上乗せ支援がある市 | `{市}で会社設立｜市独自の上乗せ支援と登録免許税半額の条件【{YYYY}年{M}月更新】` |
| 無料講座がある市 | `{市}で会社設立｜無料で登録免許税を半額にする方法と講座一覧【{YYYY}年{M}月更新】` |
| 標準 | `{市}で会社設立｜登録免許税が半額になる制度と創業セミナー【{YYYY}年{M}月更新】` |

### meta description（120字目安）

```
{市}で会社を設立すると登録免許税が15万円→7.5万円に。条件は{市}の特定創業支援等事業を
{N}回以上・1か月以上受講すること。対象講座{N}件（最安{金額}）、申請手順、{市}独自の
上乗せ支援まで{YYYY}年{M}月時点の情報でまとめました。
```

## 4. 自動生成ページを「薄い」と判定させないために

1,459ページの機械生成は誘導ページ判定のリスクがあります。**テンプレに市名を差し込むだけなら確実に飛びます。**

回避の根拠は、**自治体ごとに独自制度が実在すること**。調査で確認できた例:

| 市 | 独自の差分 |
|---|---|
| 福岡市 | 登録免許税で浮かない残り半額を**市が独自に支援** |
| 那覇市 | 沖縄振興開発金融公庫、沖縄県創業者支援資金の自己資金要件 20%→10% |
| 板橋区 | 融資の利子補給を通常より1割加算、専門家派遣が創業前 年5回無料 |
| 高松市 | コワーキング co-ba takamatsu の入会金免除 |
| 川崎市 | 起業家オーディション最終選考進出でも証明書が出る |
| 横浜市 | 商店街空き店舗開業支援事業、スタートアップおうえん資金（保証料全額助成） |
| 松戸市 | 市独自の登録免許税補助金 |

**最低限の差別化要件（1ページあたり）**
- 講座名・実施機関・受講料の実データを3件以上
- その市固有の制度を1つ以上
- 出典URLと最終確認日

これを満たせない市は**公開しない**。埋めるより落とすほうが安全です。

## 5. 構造化データ

| ページ | schema |
|---|---|
| 地域ページ | `FAQPage`（H2よくある質問）+ `BreadcrumbList` |
| 講座モジュール | `Event`（startDate / location / offers / eventAttendanceMode） |
| 比較ページ | `ItemList` |

**注意:** 調査した18ソースのうち、`Event` 型のJSON-LDを出していたのは**高松商工会議所のみ**でした。自治体は全滅（Article/WebPageのみ）。つまり**Event schemaを正しく出すだけで構造化データ上の優位が取れます**。

## 6. 公開順序

1. **`/compare/fee/`（受講料比較）を最初に1本。** 手元のデータで今すぐ書ける。被リンクと指名検索の入口
2. **中規模都市の地域ページを50〜100。** 横浜・大阪はfreeeとアントレサロンがいるので後回し。空白地帯で先に順位を作る
3. `/seido/` 4本
4. 反応を見て地域ページを拡大

---

## 7. やらないこと

- **「◯◯市 特定創業支援等事業」をtitleに置く。** 市の公式に勝てません
- **イベントに個別URLを与える。** 腐ります
- **1,459件を一気に生成する。** 差分データが揃った市から出す
- **受講料や日付をテンプレの空欄のまま公開する。** 薄いページ判定の直行便です
