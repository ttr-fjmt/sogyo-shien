## タスク1：競合のカバー範囲 ── 前回の見立ては誤りでした

### freee（www.freee.co.jp）

robots.txt は拡張子（`*.pdf$` 等）のみを禁止し、sitemap を公開しています。`/kb/sitemap-0.xml` を取得して全数を数えました。

| 項目 | 実測値 |
|---|---|
| kb配下の総URL | 2,747 |
| 会社設立カテゴリ（kb-launch） | 255ページ |
| **自治体別ページ（launch-in-*）** | **2件のみ** |

該当したのは `launch-in-yokohama` と `launch-in-fukuoka` の2つだけでした。大阪・名古屋・札幌・神戸・京都・川崎・さいたま・広島・仙台・千葉のいずれもヒットしません。

**freeeはトピック別に255本書いているのであって、地域別には展開していません。**

### アントレサロン（entre-salon.com）

sitemap がないため `/kigyo/{city}/` を13都市で実測しました。

- **200（存在）: 横浜・川崎・さいたま の3件**
- 404: 大阪・名古屋・福岡・神戸・板橋・高松・金沢・川口・那覇・松本

同社はコワーキング運営で、ページは物理拠点（東京・神奈川・埼玉）に連動しています。全国SEO施策ではありません。

### 訂正と結論

**前回「freeeが自治体別ページを量産している」と述べましたが、これは誤りでした。**実測では2件です。

したがって**狙う自治体を中規模以下に限定する必要はありません。**地域×成果の層は政令市を含めて実質的に空いており、競合がいるのは横浜市と福岡市だけです。皮肉なことに、この2市は本サイトが既にデータを持っている市です。

### 歩留まり

- **WP REST APIが生きている：7／11（64%）**
- **イベント/セミナー専用の投稿タイプを持つ：3／11（27%）**（高松・那覇・岡山）
- **robots.txt でAPIパスを禁止：0／11**

### 見つかった逆転現象

**大都市の会議所（東京・大阪・名古屋・仙台）はWordPressではなく独自システムで、APIがありません。**一方、中小規模の会議所はWordPressが主流でAPIが開いています。

つまり**ロングテールほど自動収集しやすい**という、通常とは逆の構造になっています。本サイトが狙う層と、自動化しやすい層が一致しています。

### 収集手順（定型化できます）

1. `/robots.txt` を確認
2. `/wp-json/wp/v2/types` で投稿タイプを取得
3. `seminar` / `events` / `tribe_events` があればそこを、なければ `posts` を収穫
4. `modified_gmt` で差分検知

## タスク3：利用条件・著作権

8自治体を調査し、6自治体で本文を確認できました。既確認の横浜市・川崎市と合わせて整理します。

| 自治体 | リンク | 転載・再利用 | 評価 |
|---|---|---|---|
| **大阪市** | — | 対象ページに**CCライセンス**表記 | **最良** |
| **横浜市** | 自由・報告不要 | 原則不可だが「**数値データ、簡単な表・グラフ等は著作権の対象外**」と明記 | **最良** |
| **名古屋市** | 自由 | 私的複製に加え、**条件を満たせば事業活動での複製利用も特例的に許可** | **寛容** |
| 那覇市 | リンクフリー・**連絡不要** | 私的使用・引用を除き無断複製・転載禁止 | 良好 |
| 高松市 | **原則リンクフリー** | — | 良好 |
| 川崎市 | 自由・許可不要（出典明示） | 転載は**事前連絡**かつ改変不可 | 注意 |
| 板橋区 | **トップページに関しては**原則自由 | 私的使用・引用を除き無断複製・転用不可 | 注意 |
| 松本市 | 原則自由だが「**トップページへお願いします**」 | 無断使用・複製・転載・改変を禁止 | 注意 |
| **福岡市** | **トップページ以外の個別ページへのリンクは、各ページの担当課に問い合わせ** | オープンデータは商用含め自由 | **最も厳しい** |
| 川口市 | 「このサイトについて」に記載を確認できず | 同左 | **未解決** |

### 判断

**このサイトの設計（事実データの要約＋リンク送客）を禁止している自治体はありませんでした。**開催日・受講料・定員といった事実そのものに著作権は及びません。横浜市はそれを明文で認めており、大阪市はCCライセンス、名古屋市は事業利用の特例まで置いています。

ただし2点、運用上の注意があります。

**1. 福岡市の個別ページへのリンクは要問い合わせと明記されています。**日本の法律上リンクは自由で、これは要請であって禁止ではありません。ただし出典として個別ページへ深くリンクする設計なので、福岡市を公開する前に担当課へ一報を入れておくのが安全です。松本市・板橋区も「トップページへ」と書いていますが、こちらは表現がより緩やかです。

**2. 告知文をそのまま転載しないこと。**川崎市・松本市・那覇市・板橋区はいずれも無断転載を禁止しています。現在の実装は事実を構造化して表示し、説明文は独自に書いているので問題ありませんが、この方針は崩さないでください。
